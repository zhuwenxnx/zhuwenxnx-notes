# zhuwenxnx-notes

Python · CUDA · Networking

折腾中的小玩具

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zhuwenxnx-notes.git
cd zhuwenxnx-notes
pip install -r requirements.txt
```
